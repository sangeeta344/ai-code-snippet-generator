# Known Limitations

## General
1. Generated code may require developer review before production use.
2. Syntax validation does not guarantee functional correctness.
3. Complex or vague requirements may produce incomplete outputs.
4. Arbitrary generated code should not be executed for safety.

## Multilingual novelty
5. Translation can lose technical meaning for vague requirements.
6. Mixed-language input can be harder to interpret.
7. Urdu may require right-to-left interface support.
8. Users should review the translated requirement before code generation.
9. Translation quality may vary by language.
10. Explanation quality may vary by language.

Any limitation that depends on the final implementation must be confirmed after integration.
