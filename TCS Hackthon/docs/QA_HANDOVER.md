# QA Handover — Development Team Requirements

When a module is ready, provide:

1. Latest Git branch/commit
2. Module/file name
3. Function/class names
4. Module responsibility
5. Required packages
6. Required environment variables (never send API keys)
7. How to run the module/application
8. Expected input/output
9. Supported languages
10. Translation provider/model
11. Normalization output schema
12. Explanation translation behavior
13. Known limitations
14. Known issues

After handover, QA will:
- Integrate locally
- Run the 36 existing general tests
- Run multilingual tests
- Run safety tests
- Record bugs
- Run automated tests
- Retest fixes
- Calculate final metrics
- Capture evidence screenshots
