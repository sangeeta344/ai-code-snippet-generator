# Bhasha2Code — QA Package

This package contains the QA/testing infrastructure for the multilingual requirement-to-Python-code novelty.

## Novelty
The proposed feature is **Multilingual Requirement Intelligence**:
regional-language or mixed-language requirement -> language detection -> translation -> technical normalization -> user confirmation -> Python code generation -> safety/syntax validation -> explanation in the preferred language.

## QA scope
- General Python code-generation testing
- Multilingual translation/meaning preservation
- Requirement normalization
- End-to-end multilingual integration
- Safety testing
- Syntax validation
- Bug tracking
- Final metrics and evidence

## Important
This package contains QA infrastructure only. It does not claim that any development module is implemented or passing.
